# MIP-8 ISA Specification
Version: 1.1

---

# CPU Overview

MIP-8 (Mini Instruction Processor - 8 bit)

Architecture:
- 8-bit Datapath
- 16-bit Instructions
- 8-bit Address Space
- 4 General Purpose Registers
- 256 Bytes RAM
- 256 Instructions ROM
- Single-cycle execution
- Hardwired combinational control decoder

---

| Binary | Register |

| 11 | R3 |

# Instruction Format

```text
15          12 11    10 9      8 7              0
+-------------+--------+--------+----------------+
|   OPCODE    |   RD   |   RS   |   IMMEDIATE   |
+-------------+--------+--------+----------------+
```

- OPCODE : 4 bits
- RD : Destination Register
- RS : Source Register
- Immediate : 8 bits

# Opcode Table

The opcode assignments below describe the implemented MIP-8 hardware decoder.

| Opcode | Mnemonic | Description |
|--------|----------|-------------|
| 0000 | NOP | No operation |
| 0001 | STORE | RAM write |
| 0010 | LOAD-MEM | RAM read / output enable |
| 0011 | MOV | Register write |
| 0100 | ADD | ALU operation |
| 0101 | SUB | ALU operation |
| 0110 | AND | ALU operation |
| 0111 | OR | ALU operation |
| 1000 | XOR | ALU operation |
| 1001 | NOT | ALU operation |
| 1010 | INC | ALU operation |
| 1011 | DEC | ALU operation |
| 1100 | LOAD | Immediate or memory load, selected by RS |
| 1101 | JMP | Jump |
| 1110 | JZ | Jump if ZERO |
| 1111 | HALT | Stop processor |

---

# LOAD

The implemented decoder uses opcode `1100` (`D12`) for LOAD.

The RS field selects the LOAD path:

| RS | LOAD Mode |
|----|-----------|
| 00 | Immediate |
| 11 | Memory |

The decoder generates register write enable from the LOAD path together with the ALU/register-write instructions.

---

# Decoder

The 4-bit opcode is decoded into one-hot signals:

| Signal | Opcode |
|--------|--------|
| D0 | 0000 |
| D1 | 0001 |
| D2 | 0010 |
| D3 | 0011 |
| D4 | 0100 |
| D5 | 0101 |
| D6 | 0110 |
| D7 | 0111 |
| D8 | 1000 |
| D9 | 1001 |
| D10 | 1010 |
| D11 | 1011 |
| D12 | 1100 |
| D13 | 1101 |
| D14 | 1110 |
| D15 | 1111 |

Implemented control signals:

```text
RAM_WE = D1
RAM_OE = D2
RAM_CS = D1 OR D2
```

Register write enable:

```text
REG_WE =
    D3 OR D4 OR D5 OR D6 OR D7 OR D8 OR D9 OR D10 OR D11
    OR LOAD_IMM
    OR LOAD_MEM
```

LOAD detection:

```text
LOAD = D12 AND NOT(D13) AND NOT(D14) AND NOT(D15)

LOAD_IMM = LOAD AND (RS = 00)
LOAD_MEM = LOAD AND (RS = 11)
```

Jump and halt controls:

```text
JMP  = D13
JZ   = D14
HALT = D15
```

---

# Flags

The ALU provides:

- ZERO
- CARRY

ZERO is asserted when the ALU result is zero.

CARRY is generated by the ALU for arithmetic operations.

The ZERO flag is used by the JZ control.

Outputs:



# Execution Flow

```text
PC
 |
 v
ROM
 |
 v
Instruction Register
 |
 v
Decoder
 |
 +---------> Register Bank
 |
 +---------> ALU
 |
 +---------> RAM
 |
 +---------> Program Counter
```

MIP-8 uses a single-cycle datapath with hardwired combinational control.
